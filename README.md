# coursework-algorthms
Hotel Management API (Курсовой проект)
Веб-приложение для управления гостиницей на базе FastAPI и SQLAlchemy. Проект демонстрирует гибридную архитектуру: реляционная БД (SQLite) выступает как постоянное хранилище, а при запуске сервера данные загружаются в оперативную память в виде кастомных структур. Это обеспечивает сверхбыстрый поиск и обработку запросов без потери данных между перезапусками.

Особенности (Алгоритмы и структуры данных)
Вместо стандартных коллекций Python, в ядре сервиса реализованы:

Хеш-таблица (метод цепочек) — для хранения постояльцев. Реализовано автоматическое рехэширование при превышении коэффициента загрузки (0.75). Поиск гостя по паспорту выполняется за время O(1).
АВЛ-дерево (сбалансированное дерево поиска) — для хранения номеров. Вставка, удаление и поиск осуществляются за O(log N).
Циклический односвязный список — хранит журнал заселений. Поддерживает автоматическую сортировку методом быстрой сортировки Хоара (Quicksort) по номеру комнаты.
Алгоритм Боуера-Мура — используется для поиска номеров по фрагменту оборудования (реализован как прямой обход АВЛ-дерева + поиск подстроки).
Технологический стек
Backend: FastAPI, Uvicorn
Database: SQLite, SQLAlchemy (ORM)
Validation: Pydantic v2
Frontend: Vanilla JS, Jinja2 (админ-панель в строгом стиле)
Запуск проекта
Клонировать репозиторий:
git clone https://github.com/ТВОЙ_НИК/hotel-algo-api.gitcd hotel-algo-api
Создать виртуальное окружение и установить зависимости:
bash

python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
Запустить сервер:
bash

uvicorn app.main:app --reload
Открыть интерфейс в браузере:
Веб-интерфейс (UI): http://127.0.0.1:8000/
Документация API (Swagger UI): http://127.0.0.1:8000/docs
Структура API
Метод
Эндпоинт
Описание
POST	/api/guests/	Регистрация гостя (вставка в Хеш-таблицу + БД)
GET	/api/guests/{passport}	Поиск гостя по паспорту (O(1))
POST	/api/rooms/	Добавление номера (вставка в АВЛ-дерево + БД)
GET	/api/rooms/search/?equipment=Wi-Fi	Поиск номеров по оборудованию (Boyer-Moore)
POST	/api/stays/check-in	Регистрация заселения (вставка в Циклический список + БД)
